# 📖 About

Git & GitHub Academy is an interactive learning platform designed for **complete beginners** who want to master Git and GitHub.

Unlike traditional tutorials that simply explain commands, this platform teaches through **real-world scenarios**, **interactive visualizations**, **hands-on practice**, and **AI-powered guidance**.

The goal is to help learners truly understand **why** Git exists before learning **how** to use it.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
